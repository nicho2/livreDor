# Vision produit

## Proposition
LivreDor permet à un groupe de construire collectivement le souvenir numérique d'une personne ou d'un événement.

Le cas initial est un départ en retraite. L'application doit cependant rester générique afin de pouvoir servir demain pour un anniversaire, un mariage, un départ, un hommage ou un événement associatif.

## Valeur
Trois éléments donnent l'essentiel de la valeur :
1. simplicité de contribution ;
2. construction collective d'une histoire ;
3. restitution pérenne à la fin du projet.

## Cycle de vie

```text
Création du projet
        ↓
Invitation / partage
        ↓
Contributions
        ↓
Mur + chronologie
        ↓
Événement
        ↓
Clôture
        ↓
Export site statique + archive complète
```

## Anti-objectifs
LivreDor n'est pas :
- un réseau social ;
- une plateforme communautaire permanente ;
- une GED ;
- un outil de stockage illimité ;
- un éditeur de site généraliste.
