# Médias synthétiques — seed-v1

Aucune photo personnelle, personne réelle, voix ou musique commerciale.

Les deux PNG ont été générés avec l'outil intégré `image_gen`, le 3 octobre 2026.
Prompts :

- `cafe.png` : illustration éditoriale chaleureuse d'une pause café fictive ;
  tasses, carnets, bouquet, aucune personne ; format paysage, texture papier ;
  carte lisible « TEST — SOUVENIR FICTIF », sans marque ni logo.
- `sortie.png` : illustration en papier découpé d'une sortie fictive au bord
  d'un lac ; barque vide, pique-nique et ballons, aucun lieu réel ni personne ;
  format paysage, panneau « TEST — SORTIE FICTIVE », sans marque ni logo.

`animation.mp4` : mire animée générée par FFmpeg, texte « TEST SYNTHETIQUE -
LivreDor », 6 secondes, 640 × 360, 24 fps, H.264 / yuv420p et AAC, faststart.
`signal.wav` : signal sinusoïdal synthétique 440 Hz de 3 secondes à faible volume,
PCM 16 bits, 48 kHz mono. Attention : ce sont des sons de test, pas des voix.

Les médias sont fournis prêts à uploader : FFmpeg n'est pas nécessaire pour
exécuter le script d'alimentation. Ce petit jeu ne teste pas les tailles limites,
les vidéos de téléphone ni tous les codecs.
